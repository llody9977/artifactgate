# Security policy

Please use [GitHub private vulnerability reporting](https://github.com/llody9977/artifactgate/security/advisories/new).
Do not publish suspected vulnerabilities, credentials, exploitable deployment details
or unredacted scan artefacts in a public issue.

Reports should identify the affected workflow, script, policy or image digest and
include safe reproduction details. Upstream n8n vulnerabilities should normally be
reported to n8n unless this repository introduces or mishandles the issue.

This is a personal project without a guaranteed response or remediation time. I will
try to acknowledge a credible report within seven days.

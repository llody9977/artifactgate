What a promotion means

A successful promotion means the bundle passed the documented checks or an explicit, expiring exception was approved. It does not certify that either image is vulnerability-free or suitable for a particular environment.

Evidence boundaries

Tracee results cover only the exercised smoke-test paths. “Not observed” does not prove that vulnerable code is unreachable. KEV, EPSS and scanner data can be delayed, revised, incomplete or incorrect.

Verify before deployment

gh attestation verify oci://IMAGE@sha256:DIGEST -o llody9977

Both the n8n image and external runner must be verified and deployed by immutable digest.
